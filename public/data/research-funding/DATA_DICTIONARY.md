# Data dictionary: public funding tables

Files in this folder are generated by `funding/tools/build_public_exports.py` from the canonical datasets in
`funding/data/`. Do not edit them by hand; change the canonical data (or the classification files in
`funding/validation/classification/`) and rebuild. The CSV and the JSON of each pair hold the same rows in the same order
with identical display fields; the JSON adds a `details` object per row with the full underlying record.

| File | Contents |
|---|---|
| `research_grants.{csv,json}` | Cash awards that fund a research project and were not excluded from publication. The main display table. |
| `other_research_support.{csv,json}` | Mechanisms that are useful but are **not** cash research grants: prizes for completed work, travel or conference awards, crowdfunding platforms, in-kind support or credits, fee-based research services (IRB review), loan repayment, fellowships, affiliation routes. Shown separately so they are never presented as grants. |
| `excluded_reviewed.{csv,json}` | Programs that were researched and reviewed but excluded from the two tables above (irrelevant, expired or discontinued, or clearly ineligible for both an independent chiropractor and any plausible AOI route). Kept for transparency; the `exclusion_reason` column says why. |

Sort order of the two main tables: `aoi_affiliation` (Independent, Independent / AOI, AOI Affiliation Suggested,
AOI Affiliation Required, Eligibility Unconfirmed), then maximum award ascending (small awards first; unpublished amounts last), then name.

## Display fields (CSV columns; top-level JSON keys)

Data keys are stable snake_case identifiers and must not be renamed. The web page should show each key under the
display heading given in the second column; in particular the `aoi_affiliation` key is displayed as **Application Pathway**.


| Field (data key) | Display heading | Meaning | Source |
|---|---|---|---|
| `record_id` | Record ID | Stable program identifier (`PRG-0001` …). Never reused. | `programs.id` |
| `program_name` | Program | Program name as published. | `programs.name` |
| `funding_organization` | Funding organization | Organization that runs the program. | `organizations.name` via `programs.organization_id` |
| `mechanism` | Mechanism | Plain-language mechanism label (Research grant; Prize for completed work; Travel or conference award; Crowdfunding platform; In-kind support or credits; Research service (fee-based); Loan repayment; Fellowship or training award; Other mechanism). | `programs.mechanism_type` |
| `award_amount` | Award amount | Human-readable amount: "USD 3,000 to 5,000", "up to USD 10,000", "typically …", or "not published". Never estimated. | `award_min`, `award_max`, `award_typical`, `currency` |
| `award_min`, `award_max` | Award minimum, Award maximum | Numeric bounds, blank when not published. | `programs.award_min`, `award_max` |
| `currency` | Currency | ISO 4217 code. | `programs.currency` |
| `research_categories` | Research categories | Research disciplines the funder names, as recorded by the researcher; semicolon-separated. | `programs.research_disciplines` |
| `eligible_study_types` | Eligible study types | Study designs the funder names or the researcher judged eligible; semicolon-separated. | `programs.eligible_study_designs` |
| `aoi_affiliation` | Application Pathway | How a member can apply. One of Independent, Independent / AOI, AOI Affiliation Suggested, AOI Affiliation Required, Eligibility Unconfirmed; definitions below and in README. AOI membership alone never satisfies a university, nonprofit, geographic, professional or other institutional requirement; those are in `additional_eligibility_requirements`. | `programs.aoi_affiliation` |
| `additional_eligibility_requirements` | Additional eligibility requirements | Mandatory qualifications that AOI affiliation does **not** satisfy: a university or hospital appointment, society membership, a degree, a career stage, residence or an in-state entity, a topic restriction. Blank when none is published. | `programs.other_qualifications_required` |
| `application_deadline_or_cycle` | Application deadline or cycle | The next known deadline (ISO date) with the cycle, or the cycle with the last known deadline and "next cycle not yet published". A past deadline is never shown as upcoming. | `programs.known_deadlines`, `application_cycle` |
| `application_status` | Application status | Status as of the verification date, from the QA-reviewed record: "Open (verified on verification date)", "Closed; recurs (next cycle not yet posted)", "Recurring; next cycle not yet posted", "Discontinued", "Unknown". It is never inferred from a projected deadline. | `programs.current_status` |
| `official_program_url` | Official program URL | Official program page. | `programs.program_url` |
| `verification_date` | Verification date | Latest access date of the evidence records cited by the program (ISO date). | `evidence.date_accessed` |
| `eligibility_notes` | Eligibility notes | Plain-language note (40 words or fewer) on who can apply and the main condition. | `programs.display_eligibility_note` |
| `exclusion_reason` | Exclusion reason | `excluded_reviewed` only: why the program is not in the two main tables. | `programs.publication_reason` |

### Application Pathway values (`aoi_affiliation`)

| Value | Definition |
|---|---|
| Independent | A member can apply without AOI involvement, either individually or through a qualifying private-practice entity. Other eligibility conditions may still apply. |
| Independent / AOI | Both a qualifying independent or practice route and an organizational route involving AOI may be available. |
| AOI Affiliation Suggested | A qualifying organization, sponsor or collaborator is needed or beneficial. AOI is a possible option, but not necessarily the only one. |
| AOI Affiliation Required | Reserved for programs specifically requiring AOI involvement. No current programs have this classification; the legend may omit it until it is needed. |
| Eligibility Unconfirmed | Available evidence does not establish a reliable application pathway. |

## `details` object (JSON only)

The full underlying record for readers who need more than the display table: `organization_id`, `organization_url`,
`organization_type`, `funding_category`, `mechanism_type`, `application_url`, `award_typical`, `funding_duration`,
`application_cycle`, `known_deadlines` (each with its evidence id), `current_status`, `applicant_types_eligible`,
`applicant_restrictions`, `institutional_affiliation_required`, `membership_required`, `membership_details`,
`geographic_eligibility`, `geographic_notes`, `independent_clinician_eligibility`, `independent_clinician_notes`,
`irb_requirements`, `application_requirements`, `allowable_expenses` (per expense category: permitted / prohibited /
conditional / unknown; `ai_subscriptions` is never assumed permitted), `allowable_expenses_notes`, `relevance_to_aoi`,
`relevance_notes`, `aoi_affiliation_reasoning` (the published rule and why the classification follows),
`aoi_affiliation_evidence_ids`, `classification_change_note` (what changed when the scheme was refined on 2026-10-20 and why), `publication_reason`, `confidence`, `qa_status`, `qa_notes`, `evidence_ids`.
Field semantics follow `funding/staging/CONTRACT.md`; evidence records (URL, quote, access date) are in
`funding/data/evidence.json`.

## Conventions

- Unknown is blank (CSV) or `null` (JSON), never a guess. "not published" in `award_amount` means the funder does not state an amount.
- All verification dates are 2026-10-20 unless a later targeted check updated a record.
- Currency is as published; no conversion is applied.
- Text contains no personal data, no local file paths and no credentials; the validator checks this on every build.
